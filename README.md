# LLMBrainMod

LLMBrainMod - это мод для Stardew Valley, который добавляет интеграцию с LLM для NPC. Мод использует локальный Ollama-сервер для генерации ответов и позволяет NPC выполнять различные действия, включая квесты, рассказы, советы и многое другое.

## Особенности

- Динамические диалоги с NPC, генерируемые с помощью LLM
- Система квестов с возможностью получения вознаграждений
- Учет физического состояния NPC (сытость, выносливость)
- Возможность получения еды и других предметов от игрока

## Требования

- Stardew Valley (версия 1.5+)
- SMAPI (версия 3.0+)
- Установленный Ollama с моделью phi3:mini

## Установка

1. Установите SMAPI для Stardew Valley
2. Установите Ollama и запустите `ollama run phi3:mini`
3. Скачайте последнюю версию LLMBrainMod
4. Поместите файлы мода в папку `Mods` в директории Stardew Valley
5. Запустите игру через SMAPI

## Настройка

Убедитесь, что Ollama запущен на порту 11434 и модель phi3:mini доступна. Мод будет использовать эту модель для генерации ответов NPC.

## Использование

Подойдите к NPC (Клинт) и взаимодействуйте с ним как обычно. NPC будет генерировать уникальные ответы и может предложить квесты или поделиться информацией.
